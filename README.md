## Kairos: when and where to hunt

An Android and Galaxy Watch app that reads live weather and my trail-camera photos, then lays out the best sits for the
week. Expert hunting advice contradicts itself, so AI agents turned 75 expert videos into 434 cited lessons and flagged
the 112 places where hunters and research disagree. [See the code →](https://github.com/reidenjohnson/kairos)

## Nock: archery scoring by camera

Point a phone at an archery target and it finds every arrow hit and sends it to your Galaxy Watch. Live computer vision
was draining the phone, so profiling cut CPU use from 173% to 125% of a core. [See the code →](https://github.com/reidenjohnson/nock)

## Latch: a focus blocker that can't trap you

Tap an NFC sticker to lock the apps that pull you in, and tap again to unlock them. Calls, Settings, and emergency apps
always work, with no root or admin access. [See the code →](https://github.com/reidenjohnson/latch)
